## 原生 IP 和广播 IP，差的不是地理位置

判断标准其实就一条：**IP 的注册归属地和服务器实际所在地是否一致**。

原生 IP 是本地 ISP 或本地运营商直接持有的段，注册地在日本、机房在日本、ASN 也是那一家。广播 IP 则是商家批量购入别国的 IP 段，再用 BGP 宣告到东京节点——GeoIP 数据库可能显示"东京"，但 WHOIS 注册地和 ASN 归属会暴露它。

流媒体平台的风控看的正是后面这层。Netflix 判断你在哪个区，靠的是 IP 的注册归属，不是它的物理位置。广播 IP 在它的库里往往被标成数据中心或代理来源，于是直接拒绝。

这里有个容易被混淆的点：**原生 IP 不等于家宽 IP**。原生 IP 大多仍然是机房 IP，只是"户口"和"居住地"对得上。家宽 IP 的稀缺度更高，价格也完全是另一个量级。对绝大多数日区流媒体和账号注册场景，干净的原生机房 IP 已经够用。

### 拿到 IP 后，三步就能验完

1. **查 ASN 和注册地**。把 IP 丢进 ipinfo.io 或 bgp.he.net，看 `country` 是不是 JP，再看 `org` / ASN 是哪家。如果 ASN 属于某家国际数据中心而不是日本本土网络运营商，基本可以怀疑是广播段。
2. **看反向解析**。PTR 记录里带着 `vps`、`cloud`、`hosting`、`datacenter` 这类词，说明这是商用机房段；这不影响它是原生 IP，但意味着它很难被当成住宅用户。
3. **实测流媒体**。这是最直接的一步。用机器访问日区独占内容，能正常播放、推荐列表切成日区内容库，说明 IP 被认成日本本地地址。

顺便提醒一句：IP 检测库之间会打架。有测评记录显示，同一台东京机器的 IP，IP2Location、ipapi、IPinfo、DB-IP 都判定为日本，MaxMind 的坐标字段却落在了别的国家。所以别只看一个库就下结论，多看几个再叠加流媒体实测。
